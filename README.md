# stable-challenge-image

The reproducible **LeJEPA + ResNet-9** experiment is in
[experiments/lejepa](experiments/lejepa/README.md), including training, Slurm
launchers, fixed-fold evaluation, diagnostics, sweeps and ONNX export.



The website is published from `docs/`. Scores are generated by the administrator's evaluator. Model files remain private; participant emails appear only when anonymity is disabled.
